# algo-sort-lens

Ein interaktiver Visualizer für Sortieralgorithmen, gebaut mit HTML, CSS und Vanilla JavaScript.

## Ziel des Projekts
Verständnis von Algorithmen (Bubble Sort, Quick Sort etc.), Rendering-Schleifen und asynchronem JavaScript (`async/await`, `Promises`) für Visualisierungen vertiefen.

## Core Features
- Generierung von zufälligen Datensätzen (Visualisierung als Balkendiagramm)
- Schritt-für-Schritt-Visualisierung der Vergleiche und Tausche in Echtzeit
- Einstellbare Geschwindigkeit und Auswahl verschiedener Sortieralgorithmen
